# FitnessNutrition

## Descrierea Proiectului

FitnessNutrition este o aplicație de fitness destinată să ajute utilizatorii în 
gestionarea antrenamentelor și a nutriției. Aplicația oferă funcționalități 
precum monitorizarea progresului, creare de plan alimentar, tracking de calorii zilnice.

## Caracteristici

- Planificarea și gestionarea antrenamentelor personalizate.
- Monitorizarea progresului utilizatorului.
- Recomandări nutriționale bazate pe obiectivele individuale.
- Calculare indice BMI și a necesarului caloric zilnic.
- Calculare aport caloric zilnic și tracking de calorii.

## Tehnologii Utilizate

- **Limbaj de programare**: C#
- **Bază de date**: MySQL
- **Framework**: .NET Framework
- **Interfață Grafică**: User Controls
- **Arhitectură**: MVVM
- **Interctiune cu Baza de date** : LINQ to SQL
